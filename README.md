# 🏥 Hospital Operations & Patient Benefit Analytics

**End-to-End Data Analytics Project | Python | Pandas | Data Visualization**

## 📌 Project Overview

This project analyzes hospital operations, patient visits, waiting times, billing records, and patient satisfaction. The goal is to identify useful insights that can help improve hospital efficiency and patient experience.

## 🎯 Project Objectives

- Analyze patient demographics and patient records.
- Study hospital visits and department-wise demand.
- Identify common diagnoses and frequently visited departments.
- Analyze patient waiting time and length of hospital stay.
- Explore billing amounts, insurance coverage, and patient payments.
- Evaluate patient satisfaction and identify improvement opportunities.

## 🛠️ Tools & Technologies

- **Python** – Data analysis and processing
- **Pandas** – Data cleaning and manipulation
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Jupyter Notebook** – Project development and analysis
- **CSV** – Dataset storage

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib
   ```

4. Keep the notebook and all three CSV files in the same folder.
5. Open the notebook in Jupyter Notebook.
6. Run the cells in order.
